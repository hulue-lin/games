#项目简介



这是一个基于Python开发的轻量交互式猜数字趣味小游戏，代码逻辑简洁清晰，是非常适合Python入门学习者参考的实操项目。游戏自带友好的交互提示、完善的异常输入处理机制，支持多局连续游玩，上手门槛极低。



#功能特性



1. 每局自动随机生成1-100区间内的目标整数，答案完全随机无规律



2. 全链路输入合法性校验：自动识别非数字输入、超出1-100范围的无效输入并给出提示，无效操作不会计入猜测次数



3. 实时反馈猜测结果：直观提示当前猜测数字偏大/偏小，引导用户逐步缩小范围接近正确答案



4. 自动统计有效猜测次数，猜中后会根据猜测次数给出对应趣味评价



5. 支持多局连续游玩，无需重复启动程序，也可随时选择终止游戏退出



#运行环境要求



• Python 3.6 及以上版本（支持f-string语法即可正常运行）



• 无需安装任何额外第三方依赖库，仅调用Python内置标准库random即可实现全部功能



#快速开始



1. 将项目代码保存为 guess\_number.py 文件



2. 打开终端，切换到代码文件所在的本地目录



3. 执行运行命令即可启动游戏：



 python guess\_number.py





#游戏玩法说明



1. 程序启动后，系统已经提前生成好一个1-100之间的随机整数，你可以输入数字进行猜测



2. 每次提交猜测后，系统会给出对应提示：数字偏大时提示往小的方向调整，数字偏小时提示往大的方向调整



3. 成功猜中数字后，系统会展示正确答案和你的总有效猜测次数，并给出对应的游玩评价



4. 单局结束后，输入y即可开启全新一局游戏，输入e即可直接退出程序
